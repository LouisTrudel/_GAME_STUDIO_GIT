### Castling Rules Implemented

| Condition | Kingside (O-O) | Queenside (O-O-O) |
|-----------|----------------|-------------------|
| King not moved | ✓ | ✓ |
| Rook not moved | h-file rook | a-file rook |
| Squares empty | f, g | b, c, d |
| Not through check | f, g unattacked | c, d unattacked |
| Not in check | ✓ | ✓ |

### Usage

```javascript
// Castling moves appear in king's legal moves when valid
import { getLegalMoves } from './moveGeneration.js';

// At game start, white king on e1:
const kingMoves = getLegalMoves('e1');
// Returns: ['d1', 'd2', 'e2', 'f2', 'f1', 'g1', 'c1']
//          (normal moves + kingside g1 + queenside c1)

// Execute castling:
import { executeMove } from './moveExecution.js';
executeMove('e1', 'g1');  // Kingside: king e1→g1, rook h1→f1
executeMove('e1', 'c1');  // Queenside: king e1→c1, rook a1→d1
```
