## === PHASE 6.1: ATTACKED SQUARES VISUALIZATION ===

**Depends:** Three.js, gameState.js, moveGeneration.js
**Pattern:** Observer — attack state triggers visual updates

### New File: `src/attackedSquares.js`

**Core Features:**

1. **Attack Calculation (`getPieceAttacks`, `getAttackedSquares`)**
   - Computes all squares attacked by each piece type
   - Pawns show diagonal attack squares (not forward moves)
   - Sliding pieces stop at first blocking piece but still attack that square
   - Returns `Map<square, attackerCount>` for intensity-based rendering

2. **Visualization Rendering**
   - Blue overlays for white attacks (`0x4a90d9`)
   - Red overlays for black attacks (`0xd94a4a`)
   - Purple overlays for contested squares (`0x9b59b6`)
   - Opacity scales with attack intensity (0.25 base → 0.6 max)

3. **Overlapping Attack Handling**
   - When both colors attack same square, shows purple "contested" indicator
   - Total intensity combines both attack counts

4. **Toggle Controls (Keyboard)**
   - `A` = Toggle attack visualization on/off
   - `W` = Show only white attacks
   - `Shift+B` = Show only black attacks
   - `D` = Show both colors (default)

### Integration Points

**main.js changes:**
- Import and init `attackedSquares.js` after selection system
- Update visualization after each move completion
- Keyboard listener for toggle controls
- Exports for external access

### Usage Example

```javascript
import { toggleAttackVisualization, setAttackFilter } from './attackedSquares.js';

// Toggle on/off
toggleAttackVisualization();

// Filter by color
setAttackFilter('white');  // Only white attacks
setAttackFilter('both');   // All attacks
```
