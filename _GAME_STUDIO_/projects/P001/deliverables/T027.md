## === VISUALIZATION CONTROLS ===
**Depends:** attackedSquares.js, defendedPieces.js, threatPreview.js
**Pattern:** Observer — button state triggers visualization updates

### Implementation

Created `visualizationControls.js` with:

1. **Toggle Buttons** - Three styled buttons for Attacks (A), Defended (S), Threats (T)
   - Color-coded: Blue (attacks), Green (defended), Red (threats)
   - Active/inactive visual states with glow effects
   - Hover animations

2. **Depth Slider** - Range input for threat depth (1-3 turns)
   - Gradient background showing intensity fade
   - Live label update showing "1 turn" / "2 turns" / "3 turns"
   - Depth markers below slider

3. **Non-blocking Placement** - Fixed position top-right corner
   - Semi-transparent dark background
   - Doesn't overlap game board
   - Keyboard hints displayed at bottom

4. **Bi-directional Sync** - UI syncs with keyboard shortcuts and vice versa
