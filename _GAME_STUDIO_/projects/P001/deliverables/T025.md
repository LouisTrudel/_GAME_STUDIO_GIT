## === DEFENDED PIECES VISUALIZATION (Phase 6.2) ===
Depends: Three.js, gameState.js, attackedSquares.js, pieces.js
Pattern: Observer — defense state triggers visual updates

### Implementation

**New file: `src/defendedPieces.js`**

Core functionality:
- `getDefendedPieces(color, state)` - Calculates which pieces are defended by friendly pieces
- `initDefendedPieces(scene)` - Initializes the visualization system
- `updateDefendedVisualization()` - Refreshes glow rings based on current board state
- `updatePulseAnimation(delta)` - Animates glow rings with pulsing effect
- `toggleDefendedVisualization()` - Toggle on/off (returns new state)
- `setDefendedFilter(color)` - Filter by 'white', 'black', or 'both'

Visual indicator:
- Glowing green rings for defended white pieces
- Glowing red rings for defended black pieces  
- Pulse animation (2.5Hz) with intensity oscillation 0.2-0.8
- Ring scales 1.0-1.1x during pulse
- Multiple defenders = brighter base intensity

### Integration (main.js changes)

1. Added imports for defendedPieces.js
2. Added THREE.Clock for delta time
3. Animation loop calls `updatePulseAnimation(delta)`
4. Initialization: `initDefendedPieces(scene)`
5. Updates visualization after each move
6. Resets on new game

### Usage

```javascript
import { 
    toggleDefendedVisualization,
    updateDefendedVisualization,
    setDefendedFilter,
    isDefendedVisualizationVisible,
    getDefendedPieces,
    getSquareDefenseData
} from './defendedPieces.js';

// Toggle on/off
toggleDefendedVisualization();

// Get defense data for a square
const { defenders, isDefended } = getSquareDefenseData('d4');

// Get all defended pieces for a color
const defended = getDefendedPieces(COLORS.WHITE, state);
// Returns Map<string, number> - square notation -> defender count
```
