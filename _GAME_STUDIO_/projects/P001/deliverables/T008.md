## === PHASE 2.1: DATA MODEL ===

**File:** `projects/P001/src/gameState.js`

**Pattern:** Data-driven — board state is pure data, separate from rendering (no Three.js dependency)

### Piece Data Format

```javascript
{
  type: 'k'|'q'|'r'|'b'|'n'|'p',  // king, queen, rook, bishop, knight, pawn
  color: 'white'|'black',
  hasMoved: boolean               // For castling/pawn double-move tracking
}
```

### Board State Structure

- `board`: Map<string, Piece|null> — 64 squares ('a1' through 'h8')
- `currentTurn`: 'white'|'black'
- `moveHistory`: Array of moves
- `enPassantTarget`: string|null
- `halfMoveClock`: number (50-move rule)
- `fullMoveNumber`: number
- `kingPositions`: {white: string, black: string}

### Key Functions

| Function | Returns | Description |
|----------|---------|-------------|
| `getSquare('e1')` | `{type:'k', color:'white', hasMoved:false}` | Get piece at square |
| `getGameState()` | `GameState` | Access full state object |
| `resetGame()` | void | Reset to starting position |
| `getPieceName(piece)` | `'white king'` | Human-readable name |

### Usage

```javascript
import { getSquare, getGameState, PIECE_TYPES, COLORS } from './gameState.js';

const piece = getSquare('e1');
if (piece.type === PIECE_TYPES.KING && piece.color === COLORS.WHITE) {
  console.log('White king on e1');
}

const state = getGameState();
console.log(state.toString());  // ASCII board display
```
