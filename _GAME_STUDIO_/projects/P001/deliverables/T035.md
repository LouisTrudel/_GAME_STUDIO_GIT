## === T035 FIX: GLOW RING GEOMETRY DISPOSAL ===

**Problem:** Module-level `const glowRingGeometry` was disposed on cleanup but couldn't be recreated on re-init, causing errors when game resets multiple times.

**Fix:** Lazy initialization pattern with null reset.

### Changes to `defendedPieces.js`:

1. **Line 30**: Changed from `const` to `let` with null initial value
2. **Lines 36-45**: Added `getGlowRingGeometry()` helper for lazy creation
3. **Line 159**: Mesh creation now uses `getGlowRingGeometry()` instead of direct reference
4. **Lines 321-342**: `disposeDefendedPieces()` now:
   - Sets `glowRingGeometry = null` after disposal (allows recreation)
   - Sets materials to `null` after disposal
   - Resets `animationTime` for clean state

### Memory Lifecycle:
```
initDefendedPieces() → getGlowRingGeometry() creates if null
disposeDefendedPieces() → disposes + sets null
initDefendedPieces() → getGlowRingGeometry() creates fresh
```
