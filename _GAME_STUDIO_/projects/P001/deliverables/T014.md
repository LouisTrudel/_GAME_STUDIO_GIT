### Key Features

1. **State Update**: Moves piece data in GameState, marks `hasMoved: true`
2. **Scene Update**: Animates piece mesh from source to destination with 150ms ease-out cubic + slight arc
3. **Capture Handling**: Removes captured pieces from both state and scene
4. **En Passant Prep**: Sets/clears `enPassantTarget` for pawn double moves (Phase 4.2)
5. **Turn Switch**: Automatically switches turn after move execution
6. **Move History**: Records all moves with piece type, color, captured piece, flags

### Usage

```javascript
// Click flow: select piece → click destination → execute move
// Handled automatically in main.js click handler

// Direct API usage:
import { executeMove, getLastMove, getMoveHistory } from './moveExecution.js';

const result = executeMove('e2', 'e4');
// result: { success: true, type: 'move', captured: null, notation: 'e4' }

const lastMove = getLastMove();
// { from: 'e2', to: 'e4', piece: 'p', color: 'white', captured: null, isEnPassant: false }
```
