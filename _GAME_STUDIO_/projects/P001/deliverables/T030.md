## 7.2.1: Hover States

### Board Squares

| State | Visual | Timing |
|-------|--------|--------|
| Hover (empty) | Square brightens +15% luminance | 0ms (instant) |
| Hover (enemy piece) | Red tint overlay, opacity 0.3 | 0ms |
| Hover (own piece, your turn) | Cyan outline, 2px, opacity 0.8 | 0ms |
| Hover (own piece, not your turn) | Grey outline, 1px, opacity 0.4 | 0ms |

### Selected State
| State | Visual |
|-------|--------|
| Selected piece | Cyan glow, radius 0.3 units, pulse 0.8s cycle |
| Legal move squares | Green dot center, radius 0.15 units, opacity 0.7 |
| Capture squares | Red ring, radius 0.25 units, opacity 0.8 |

### UI Buttons (Toggle Controls)

| State | Visual |
|-------|--------|
| Default | Background #2A2A2A, text #FFFFFF |
| Hover | Background #3A3A3A, scale 1.02x, transition 100ms |
| Active (toggle ON) | Background #4A7C59, border-left 3px #7FFF00 |
| Disabled | Opacity 0.4, cursor not-allowed |

### Cursor Changes

| Context | Cursor |
|---------|--------|
| Empty square | default |
| Own piece (your turn) | pointer |
| Own piece (not your turn) | not-allowed |
| Enemy piece (capturable) | crosshair |
| Legal move destination | pointer |
| UI button | pointer |

## 7.2.2: Keyboard Shortcuts

### Visualization Toggles

| Key | Action | Feedback |
|-----|--------|----------|
| `A` | Toggle attacked squares layer | Flash button, show toast "Attacks: ON/OFF" 1s |
| `D` | Toggle defended pieces layer | Flash button, show toast "Defense: ON/OFF" 1s |
| `T` | Toggle threat preview | Flash button, show toast "Threats: ON/OFF" 1s |
| `1` / `2` / `3` | Set threat depth 1/2/3 turns | Update slider, toast "Depth: N turns" 1s |

### Game Controls

| Key | Action | Feedback |
|-----|--------|----------|
| `Escape` | Deselect current piece | Clear selection highlight |
| `R` | Reset/New game (only at game end) | Confirm dialog first |
| `F` | Flip board perspective | 500ms rotation animation |

### Navigation (Selected Piece)

| Key | Action |
|-----|--------|
| `Arrow keys` | Move selection highlight between squares |
| `Enter` / `Space` | Confirm selection/move |

### Shortcut Hints

Display shortcut hints on toggle buttons:
```
[A] Attacks  [D] Defense  [T] Threats
```
Format: Single letter in brackets, 10px smaller than label, opacity 0.6

## Success Criteria Verification

**"New player understands controls in 30 seconds"**

| Signal | Design Solution |
|--------|-----------------|
| Know how to select piece | Pointer cursor, hover highlight |
| Know valid moves | Green dots appear on selection |
| Know captures | Red rings on capturable enemies |
| Know whose turn | Turn indicator always visible |
| Know toggle functions | Labels + shortcut hints on buttons |
| Can use on mobile | Touch targets ≥44px, responsive layout |

### 30-Second Test Protocol

1. Show board (0s)
2. Player hovers/taps own piece → sees highlight (5s)
3. Player clicks/taps → sees legal moves (10s)
4. Player executes move → turn switches (15s)
5. Player notices toggle buttons, tries one (25s)
6. Player understands visualization changed (30s)

**Pass if:** Player completes move AND toggles visualization within 30s without instruction.
