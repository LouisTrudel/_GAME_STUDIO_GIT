## 3. MOVEMENT ANIMATION

### Current State
```javascript
MOVE_ANIMATION_DURATION = 150ms
Easing: cubic ease-out
Arc height: 0.15 units
```

### Polish Specification

**Timing Refinement:**
| Move Type | Duration | Easing |
|-----------|----------|--------|
| Standard move | 180ms | `easeOutCubic` |
| Capture | 200ms | `easeOutQuart` (snappier arrival) |
| Castling (king) | 220ms | `easeInOutCubic` |
| Castling (rook) | 180ms | `easeOutCubic` (follows king) |
| Long move (3+ squares) | 250ms | `easeOutQuint` (smooth decel) |

**Arc Profile:**
```javascript
// Height varies by distance traveled
const distance = Math.sqrt(dx*dx + dz*dz);
const baseArc = 0.12;
const arcMultiplier = Math.min(distance * 0.03, 0.08);
const arcHeight = baseArc + arcMultiplier;

// Peak at 40% through animation (not 50%) for anticipation
const arcT = t < 0.4 ? t / 0.4 : (1 - t) / 0.6;
const arc = Math.sin(arcT * Math.PI) * arcHeight;
```

**Easing Functions (CSS cubic-bezier equivalents):**
```javascript
easeOutCubic:  (t) => 1 - Math.pow(1 - t, 3)
easeOutQuart:  (t) => 1 - Math.pow(1 - t, 4)
easeOutQuint:  (t) => 1 - Math.pow(1 - t, 5)
easeInOutCubic: (t) => t < 0.5 
    ? 4 * t * t * t 
    : 1 - Math.pow(-2 * t + 2, 3) / 2
```

**Landing Effect:**
```javascript
// Subtle scale "settle" on landing (last 20% of animation)
if (t > 0.8) {
    const settleT = (t - 0.8) / 0.2;
    const settle = 1 + Math.sin(settleT * Math.PI) * 0.015;
    piece.scale.setScalar(PIECE_SCALE * settle);
}
```

## 4. CAMERA CONFIGURATION

### Current State
```javascript
position: (0, 12, 6)
lookAt: (0, 0, 0)
FOV: 50
```

### Polish Specification

**Adjusted Camera:**
```javascript
position: (0, 10.5, 5.5)      // Slightly lower, closer
lookAt: (0, -0.3, 0)          // Look slightly below center
FOV: 45                        // Tighter framing, less distortion
```

**Rationale:**
- Lower position creates more intimate feel
- Reduced FOV minimizes peripheral distortion
- Board fills more of frame = Monument Valley framing
- Negative lookAt.y ensures board bottom edge visible

**Aspect Ratio Handling:**
```javascript
// On resize, maintain minimum board visibility
const minVisibleBoard = 0.85;  // 85% of board always visible
const aspectRatio = window.innerWidth / window.innerHeight;

if (aspectRatio < 1) {
    // Portrait: pull camera back
    camera.position.z = 5.5 + (1 - aspectRatio) * 2;
} else if (aspectRatio > 1.8) {
    // Ultra-wide: narrow FOV
    camera.fov = 45 - (aspectRatio - 1.8) * 5;
    camera.updateProjectionMatrix();
}
```
