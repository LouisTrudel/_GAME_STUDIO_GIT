### Implementation Details

**Selection System Features:**
1. **Click to select own piece** - Only current turn's pieces selectable
2. **Highlight selection** - Yellow overlay on selected square
3. **Show legal move destinations** - Green overlay for moves, red for captures
4. **Click handling:**
   - Same square → deselect
   - Valid destination → returns move intent (for Phase 3.3)
   - Another own piece → switch selection
   - Invalid square → deselect

**Visual Highlights:**

|-----------|-------|---------|
