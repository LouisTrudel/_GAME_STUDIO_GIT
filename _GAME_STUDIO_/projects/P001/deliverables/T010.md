## === PHASE 2.3: CHECK DETECTION ===
Depends: gameState.js, moveGeneration.js (Phase 2.2)
Pattern: Data-driven — pure functions simulate moves on cloned state

### Implementation Summary

**New Functions Added to `moveGeneration.js`:**

1. **`isSquareAttacked(square, byColor, state)`** - Checks if a square is attacked by any piece of given color
   - Checks pawn diagonal attacks
   - Checks knight L-shaped attacks  
   - Checks king adjacent attacks (prevents king proximity)
   - Checks rook/queen straight-line attacks
   - Checks bishop/queen diagonal attacks

2. **`isInCheck(color, state)`** - Checks if king of given color is in check
   - Gets king position from state
   - Calls `isSquareAttacked` with enemy color

3. **`moveLeavesKingInCheck(from, to, state)`** - Simulates move and checks legality
   - Clones game state
   - Handles en passant capture (removes captured pawn)
   - Executes move on cloned state
   - Returns true if own king would be in check

**Modified Functions:**

- **`getLegalMoves()`** - Now filters pseudo-legal moves through `moveLeavesKingInCheck()`
- **`getAllLegalMoves()`** - Now filters all moves for check legality

### Usage

```javascript
import { isSquareAttacked, isInCheck, getLegalMoves } from './moveGeneration.js';

// Check if e4 is attacked by black
const attacked = isSquareAttacked('e4', 'black', state);

// Check if white king is in check
const inCheck = isInCheck('white', state);

// Get legal moves (automatically filters out moves leaving king in check)
const moves = getLegalMoves('e2'); // Pinned pieces return []
```
