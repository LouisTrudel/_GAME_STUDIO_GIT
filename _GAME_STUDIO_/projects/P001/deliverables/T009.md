### Implementation

**Per-piece movement rules:**

| Piece | Movement Logic |
|-------|----------------|
| Pawn | Forward 1 (or 2 from start), diagonal captures, en passant ready |
| Knight | L-shape offsets (8 possible squares) |
| Bishop | Diagonal sliding with blocking detection |
| Rook | Orthogonal sliding with blocking detection |
| Queen | Combined bishop + rook sliding |
| King | Single square in all 8 directions (castling deferred to Phase 4.1) |

**Blocking detection:** `getSlidingMoves()` slides in each direction until hitting:
- Board edge → stop
- Friendly piece → stop (can't capture own pieces)
- Enemy piece → include as capture, then stop
