### Core Features

1. **Threat Depth Calculation (1-3 turns)**
   - Uses breadth-first search through piece movements
   - For each piece, simulates all legal moves and calculates resulting attack patterns
   - Tracks minimum depth at which each square can first be threatened
   - Performance-optimized with position limits per depth level

2. **Fading Intensity Rendering**
   | Depth | Color | Opacity | Description |
   |-------|-------|---------|-------------|
   | 1 turn | `0xff3333` (bright red) | 0.55 | Immediate threats |
   | 2 turns | `0xff6666` (medium red) | 0.35 | Near threats |
   | 3 turns | `0xff9999` (light red) | 0.20 | Distant threats |

3. **Depth Toggle Controls**
   - `T` key: Toggle threat visualization on/off
   - `1` key: Set depth to 1 turn (immediate)
   - `2` key: Set depth to 2 turns (medium)
   - `3` key: Set depth to 3 turns (distant)
   - `Ctrl+W`: Show threats to white only
   - `Ctrl+B`: Show threats to black only
   - `Ctrl+D`: Show all threats
