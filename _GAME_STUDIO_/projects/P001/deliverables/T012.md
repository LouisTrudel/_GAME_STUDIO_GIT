## === PHASE 3.1: INPUT HANDLING ===
**Depends:** Phase 2, Three.js
**Pattern:** Observer — click events dispatch to handlers

### Files Created

**`src/input.js`** - Raycasting click detection
- `initInput(camera, boardGroup, piecesGroup)` - Initializes input system
- `setSquareClickHandler(callback)` - Sets external handler for game logic
- `handleClick(event)` - Raycasts mouse to board/pieces, logs coordinates
- `notationToWorldXZ(notation)` - Converts chess notation to world coords

**`src/turnIndicator.js`** - Turn display UI
- `initTurnIndicator()` - Creates DOM overlay showing current turn
- `updateTurnIndicator()` - Refreshes display when turn changes
- `getCurrentTurn()` - Returns 'white' or 'black'
- `switchTurn()` - Toggles turn (for Phase 3.3)

### Files Modified

**`src/main.js`** - Integration
- Added imports for input and turnIndicator modules
- Calls `initInput()` and `initTurnIndicator()` after board setup
- Sets click handler that logs: square notation, piece info, legal moves
- Exports `getCurrentTurn`, `updateTurnIndicator`, `setSquareClickHandler`
