### Implementation

**Pattern:** Component - each piece type has distinct procedural geometry

**Piece Geometries (6 types, visually distinguishable):**
| Piece | Shape | Height |
|-------|-------|--------|
| Pawn | Cylinder base + sphere head | 0.85 |
| Rook | Tower with 4 battlements | 1.15 |
| Knight | Angled neck + box head + ears | 1.1 |
| Bishop | Cone mitre + ball top | 1.35 |
| Queen | Crown with 8 spikes + ball | 1.4 |
| King | Tallest with cross on top | 1.6 |

**Colors:**
- White: `0xf5f5f5` (off-white)
- Black: `0x2c2c2c` (dark gray for depth)

### API Exported
