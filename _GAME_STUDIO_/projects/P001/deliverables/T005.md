## === PHASE 1.2: BOARD RENDERING - DELIVERABLE ===

**Depends:** Phase 1.1 (scene/camera/renderer)
**Pattern:** Component — board organized as Group containing squares and label sub-groups

### Implementation

Updated `projects/P001/src/main.js` with:

1. **8x8 Grid** - 64 squares using shared `BoxGeometry` and two materials:
   - Light squares: `#f0d9b5` (cream/light wood)
   - Dark squares: `#b58863` (walnut/dark wood)
   - Proper alternating pattern with `(row + col) % 2`

2. **Square Data** - Each square stores metadata in `userData`:
   ```javascript
   { type: 'square', file: 'a'-'h', rank: 1-8, notation: 'a1'-'h8' }
   ```

3. **Rank Labels (1-8)** - Canvas-textured sprites positioned left of board

4. **File Labels (a-h)** - Canvas-textured sprites positioned below board

5. **Exports** - `scene`, `camera`, `boardGroup`, `SQUARE_SIZE`, `BOARD_OFFSET` for Phase 1.3

### Key Constants
| Constant | Value | Purpose |
|----------|-------|---------|
| `SQUARE_SIZE` | 1 | Unit size per square |
| `BOARD_OFFSET` | 3.5 | Centers board at origin |
| `LIGHT_SQUARE_COLOR` | 0xf0d9b5 | Cream squares |
| `DARK_SQUARE_COLOR` | 0xb58863 | Walnut squares |

### Test Verification
- Browser shows 8x8 chess board with alternating cream/walnut squares
- Rank labels 1-8 visible on left side
- File labels a-h visible on bottom
- Board centered in view with cream background
- No pieces rendered (as expected for Phase 1.2)
