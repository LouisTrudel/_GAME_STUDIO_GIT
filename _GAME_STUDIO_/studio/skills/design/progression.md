# Progression Design

## Progression Types

| Type                     | Feel                             |
|--------------------------|----------------------------------|
| Linear (levels)          | Clear path, predictable          |
| Branching (skill trees)  | Choice, identity                 |
| Horizontal (collection)  | Variety, no power creep          |
| Prestige (reset)         | Fresh start, permanent bonus     |

## XP Curves

| Curve                    | Use When                         |
|--------------------------|----------------------------------|
| Linear                   | Consistent pacing                |
| Exponential              | Early rush, long endgame         |
| Logarithmic              | Fast start, slow mastery         |
| Stepped                  | Milestone moments                |

## Unlock Pacing

| Phase                    | Unlock Rate                      |
|--------------------------|----------------------------------|
| Tutorial (0-30min)       | Every 2-5 minutes                |
| Early game (1-5hr)       | Every 15-30 minutes              |
| Mid game (5-20hr)        | Every 1-2 hours                  |
| Late game (20hr+)        | Meaningful milestones only       |

## Retention Hooks

| Hook                     | Implementation                   |
|--------------------------|----------------------------------|
| Near-miss                | Show progress to next unlock     |
| Sunk cost                | Time invested visible            |
| Social comparison        | Leaderboards, achievements       |
| Collection               | "X of Y collected"               |

## Rules

- Always show progress toward next goal
- Never remove earned progress
- Parallel progression paths reduce frustration
- Prestige should feel rewarding, not mandatory
