# Lore Writing

## Lore Layers

| Layer                    | Player Access                    |
|--------------------------|----------------------------------|
| Surface                  | Everyone sees (names, visuals)   |
| Active                   | Those who read (descriptions)    |
| Hidden                   | Those who search (secrets)       |
| Meta                     | Developers only (design docs)    |

## World-Building Elements

| Element                  | Questions to Answer              |
|--------------------------|----------------------------------|
| History                  | What happened before?            |
| Geography                | Where is everything?             |
| Culture                  | What do people believe/do?       |
| Conflict                 | What tensions exist?             |
| Magic/Tech               | What are the rules?              |

## Show Don't Tell

| Tell (Avoid)             | Show (Prefer)                    |
|--------------------------|----------------------------------|
| "The war was brutal"     | Ruins, graves, veteran NPCs      |
| "Magic is rare"          | Reactions when player uses it    |
| "He's a hero"            | NPCs thank him, statues exist    |

## Environmental Storytelling

| Element                  | Story Potential                  |
|--------------------------|----------------------------------|
| Item placement           | What happened here?              |
| Architecture             | Who built this? When?            |
| Graffiti/signs           | Who lived here?                  |
| Wear patterns            | What's used often?               |

## Rules

- Consistency > creativity (don't contradict)
- Iceberg principle (know 10x what you show)
- Names should be pronounceable
- Lore rewards exploration, never punishes skipping
