# Dialogue Writing

## Line Length

| Context                  | Max Characters                   |
|--------------------------|----------------------------------|
| Speech bubble            | 60                               |
| Dialogue box             | 120                              |
| Narrator text            | 200                              |

## Voice Consistency

| Character Type           | Speech Pattern                   |
|--------------------------|----------------------------------|
| Wise mentor              | Metaphors, questions             |
| Comic relief             | Puns, exaggeration               |
| Villain                  | Dramatic, self-assured           |
| Child                    | Simple words, enthusiasm         |
| Robot/AI                 | Precise, literal                 |

## Dialogue Structure

| Beat                     | Purpose                          |
|--------------------------|----------------------------------|
| Hook                     | Get attention                    |
| Info                     | Deliver content                  |
| Choice/Action            | Player engagement                |
| Payoff                   | Reward for reading               |

## Common Mistakes

| Mistake                  | Fix                              |
|--------------------------|----------------------------------|
| Walls of text            | Break into 2-3 line chunks       |
| Exposition dumps         | Spread info across encounters    |
| All caps emotions        | Use punctuation, word choice     |
| "As you know..."         | Just state it or show it         |

## Rules

- Read aloud before shipping
- Each character has a verbal tic or pattern
- Players skim — front-load important info
- Options should be clearly different
- Never block gameplay with unskippable dialogue
