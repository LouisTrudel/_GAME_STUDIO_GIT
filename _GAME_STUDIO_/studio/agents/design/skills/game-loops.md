# Game Loops

## Core Loop Structure

```
ACTION → REWARD → PROGRESSION → ACTION
```

Every game needs this cycle to feel engaging.

## Loop Types

### Micro Loop (seconds)
- Click → feedback → click again
- Jump → land → jump again
- Example: Cookie Clicker clicking

### Core Loop (minutes)
- Gather resources → spend resources → unlock → gather more
- Fight enemy → get XP → level up → fight stronger
- Example: One play session

### Meta Loop (hours/days)
- Complete missions → unlock content → new missions
- Progress story → new areas → continue story
- Example: Overall game progression

## Designing Loops

| Element | Question |
|---------|----------|
| Action | What does player DO? |
| Feedback | What do they SEE/HEAR? |
| Reward | What do they GET? |
| Motivation | Why do they CONTINUE? |

## Common Patterns

### Incremental/Idle
```
Click → Currency → Upgrades → More currency/click
```

### Collection
```
Explore → Find items → Complete sets → Unlock rewards
```

### Combat
```
Fight → XP/Loot → Upgrade → Fight harder enemies
```

### Building
```
Gather → Craft → Place → Unlock recipes → Gather more
```

## Loop Health Check

- Is there always something to do?
- Does progress feel meaningful?
- Are rewards spaced well?
- Is there long-term goal?
