# Economy Design

## Currency Sinks & Sources

**Sources** (currency enters game):
- Quest rewards
- Enemy drops
- Daily bonuses
- Achievements

**Sinks** (currency leaves game):
- Consumables (potions, ammo)
- Upgrades
- Cosmetics
- Fees/taxes

**Rule:** Sinks must balance sources or inflation occurs.

## Pricing Psychology

| Price Point | Player Feels |
|-------------|--------------|
| 1-10 | Trivial, buy freely |
| 50-100 | Consider briefly |
| 500-1000 | Save up for it |
| 5000+ | Major goal |

## Progression Curves

### Linear
```
Level 1: 100 XP
Level 2: 200 XP
Level 3: 300 XP
```
Feels: Consistent, predictable

### Exponential
```
Level 1: 100 XP
Level 2: 200 XP
Level 3: 400 XP
```
Feels: Early progress fast, late game grindy

### Soft Cap
```
Level 1-10: Fast
Level 10-20: Medium
Level 20+: Slow
```
Feels: Accessible start, dedicated endgame

## Rarity Tiers

| Tier | Drop Rate | Power Boost |
|------|-----------|-------------|
| Common | 60-70% | Baseline |
| Uncommon | 20-25% | +10-20% |
| Rare | 8-12% | +30-50% |
| Epic | 2-4% | +75-100% |
| Legendary | 0.5-1% | +150%+ |

## Anti-Exploit Rules

- Daily/weekly caps on farming
- Diminishing returns on repeats
- Time-gates on best rewards
- Trade fees to prevent flipping
