# Dialogue Writing

## Dialogue Structure

### Basic Exchange
```
[NPC]
"Opening line - establishes mood/context."

[PLAYER]
> Option A: Direct response
> Option B: Question
> Option C: Deflection/humor

[NPC]
(responds based on choice)
```

## Character Voice Differentiation

| Trait | How It Shows |
|-------|--------------|
| Educated | Longer words, proper grammar |
| Street-smart | Slang, contractions, short |
| Ancient | Formal, archaic phrasing |
| Child | Simple words, enthusiasm |
| Villain | Condescension, threats veiled |

## Examples

### Wise Elder
```
[ELDER]
"Long have I awaited one such as you. The prophecy speaks of—"
```

### Merchant
```
[MERCHANT]
"Ah, a customer! Whatcha buyin'? Got some rare things on special today."
```

### Soldier
```
[CAPTAIN]
"Orders are orders. You want through? Show me your papers."
```

## Player Choice Design

### Meaningful Choices
```
> "I'll help you." (Accept quest)
> "What's in it for me?" (Negotiate reward)
> "Find someone else." (Decline)
```

### Avoid
```
> "Yes"
> "Tell me more"  (just delays yes)
> "No" (blocks content)
```

## Emotion Tags

Use parenthetical directions:
```
[NPC]
(nervous, avoiding eye contact)
"I... I don't know what you're talking about."

(angry, slamming table)
"Enough! I won't be interrogated!"
```

## Length Guidelines

| Context | Max Length |
|---------|------------|
| Combat bark | 5-10 words |
| Quick dialogue | 1-2 sentences |
| Story moment | 3-4 sentences |
| Lore dump | Split into pages |

## Dialogue Flow

```
Hook → Context → Choice Point → Consequence → Exit
```

- Hook: Grab attention
- Context: Why this matters
- Choice: Player agency
- Consequence: Reaction to choice
- Exit: Clear end of conversation
