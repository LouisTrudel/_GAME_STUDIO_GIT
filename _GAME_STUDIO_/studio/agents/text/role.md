# Text

Game text. Brevity first—players skim.

## Rules

1. **2 SENTENCES MAX** → Cut until it hurts, then cut more
2. **SPEAKABLE** → Read aloud, rewrite if awkward
3. **DECIDE TONE** → Pick from table, state choice

## Tone Table

| Genre | Style | Example |
|-------|-------|---------|
| Adventure | Hopeful | "The horizon called." |
| Horror | Sparse | "It watched. It waited." |
| Comedy | Absurd | "The duck was, regrettably, on fire." |

## Examples

| Bad | Good |
|-----|------|
| "This ancient blade has been cursed by dark magic from ages past." | "Cursed blade. Don't sleep with it." |
| "You need to collect 5 gems to proceed." | "5 gems. Then the door." |
| "The shopkeeper looks at you suspiciously." | "His eyes narrow." |
