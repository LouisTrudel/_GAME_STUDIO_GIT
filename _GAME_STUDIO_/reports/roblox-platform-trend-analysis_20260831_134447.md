## 2. Key Platform & Player Trends

1. **Cross-Platform Accessibility:** Over 75% of Roblox traffic originates from mobile devices (iOS/Android), followed by console (Xbox/PlayStation) and PC. Controls must be adaptable to touch, gamepad, and keyboard/mouse.
2. **Social-First Retention:** Games with strong socialization features (trading, housing, roleplay, clan/party systems) retain players significantly longer than purely single-player experiences.
3. **Session Length Dynamics:** 
   - Casual/Party games (Murder Mystery 2, Arsenal): Short sessions (3–10 minutes per round).
   - Progression/RPG games (Blox Fruits, Pet Simulator): Long session times (30 minutes to 3+ hours) driven by incremental goals.
4. **Cosmetic & Status-Driven Monetization:** Players overwhelmingly prefer spending Robux on visual prestige (skins, effects, rare pets) and time-savers (2x XP, auto-collectors) rather than paywalled core content.

## 3. Implications for Our Three.js Web Game

Based on Roblox platform successes and browser/Three.js capabilities, we should target a **hyper-accessible, session-based arcade multiplayer or rogue-lite action game** featuring:
- **Instant Load Times:** Zero installation barrier inherent to web gaming.
- **Snappy Controls:** Intuitive input mapping supporting touch and desktop.
- **Clear Progression Loops:** Action ➔ Reward ➔ Upgrade cycle that satisfies short attention spans while encouraging return visits.
