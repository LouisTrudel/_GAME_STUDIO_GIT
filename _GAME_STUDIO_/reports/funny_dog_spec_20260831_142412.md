# Character Specification: Goofy Low-Poly Dog

## Visual Description
A stylized, low-poly cartoon dog designed for high performance in a web-based game environment. 
- **Expression:** Wide, uncoordinated eyes, tongue lolling out of the side of the mouth, ears mismatched (one floppy, one perked).
- **Geometry:** Heavy use of flat shading, limited vertex count (~500 polys).
- **Proportions:** Exaggerated head-to-body ratio.

## Colors
- **Primary (Fur):** #FF9F1C (Vibrant Orange)
- **Secondary (Ears/Spots):** #FFD166 (Sunshine Yellow)
- **Accent (Tongue):** #EF476F (Playful Pink)
- **Eyes/Nose:** #073B4C (Deep Navy/Black)

## Dimensions/Size
- **Scale:** 1.0 unit (approx. dog-sized in game world)
- **File Format:** .GLB (for Three.js integration)

## Style Reference
"Like 'Animal Crossing' or 'Untitled Goose Game' but with a more distinct, vibrant low-poly edge."

## Mood
Playful, chaotic, energetic, and highly readable from a distance.
