1. **studio-agents.js as owner**: Since it loads after studio.js and contains more sophisticated logic (e.g., updateAgentStatsInPlace), it's the single source for all agent-related rendering.

2. **studio-core.js for utilities**: formatTokens, formatUptime, and other formatting functions remain in studio-core.js as shared utilities.

3. **Load order safety**: Functions are called during initialization (studio-core.js's initApp), which happens after all scripts load, so studio-agents.js functions are available.

4. **HTML structure preserved**: agents-cards div correctly targeted by renderAgentCards, terminal dock remains separate.
