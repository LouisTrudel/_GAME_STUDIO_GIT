### Design Rationale

| Decision | Rationale |
|----------|-----------|
| Minimal role.md (2 lines) | Only identifies the model - no instructions, skills, or constraints |
| No tools.py | No custom tools - uses raw Claude CLI capabilities |
| No router skill | `None` in map → `load_router_skill()` returns empty string |
| `"vanilla": true` flag | Explicit marker for downstream code to skip context injection |
| Color `#d4a574` | Warm beige/tan - neutral, distinct from other agents |

### What Gets Injected

| Component | Standard Agent | CLAUDE Agent |
|-----------|----------------|--------------|
| role.md | Full role instructions | 2 lines (identity only) |
| Router skill | Agent-specific routing | None |
| Shared skills | All shared/*.md | Yes (unless filtered by `vanilla` flag) |
| Tools | Agent-specific | None |
| Task context | Yes | Yes (unless filtered by `vanilla` flag) |

### Usage

To fully isolate vanilla Claude responses, consuming code should check `config.vanilla == true` and skip:
- Shared skill injection
- Task context injection
- Any studio-specific system prompts

This enables A/B testing: same prompt → compare studio-augmented agent vs raw Claude CLI.
