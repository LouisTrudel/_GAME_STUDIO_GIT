### Root Cause

The backend looked for `white_paper.md` (with underscore) but project files use `whitepaper.md` (no underscore).

### Change Made

**File:** `studio/core/projects.py:234-248`

Modified `read_document()` to support both filename conventions:
- `whitepaper.md` (preferred, matches actual files)
- `white_paper.md` (legacy/alternate)

```python
# Support both naming conventions (whitepaper.md and white_paper.md)
if doc_type == "white_paper":
    candidates = ["whitepaper.md", "white_paper.md"]
else:
    candidates = ["roadmap.md"]

doc_path = None
for filename in candidates:
    candidate_path = project_path / filename
    if candidate_path.exists():
        doc_path = candidate_path
        break
```
