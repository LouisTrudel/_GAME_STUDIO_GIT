### Task Flow

```
PENDING →(deps met)→ READY →(claimed)→ IN_PROGRESS →(success)→ APPROVED
                                            ↓
                                         (error)
                                           ↓
                                      FAILED/ERROR
```

| Parameter | Value |
|-----------|-------|

### Memory Tiers (AC-Memory)

| Tier | Size Limit | Injected | Purpose |
|------|------------|----------|---------|

### Issues & Improvement Opportunities

| Priority | Issue | Current | Proposed |
|----------|-------|---------|----------|
| High | Sync message processing | Blocks on memory/history | Async queue |
| High | Fallback compression | 50/50 split | Keyword extraction |
| High | Dependency lookup | Linear archive scan | In-memory graph |
| Medium | Memory tier growth | tier3+ grows to 5MB+ | Periodic rollover |
| Medium | WebSocket traffic | Full JSON per update | Delta encoding |
| Low | Vanilla mode | Two code paths | Always inject |
