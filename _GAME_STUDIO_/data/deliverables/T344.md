```python
from studio.core.projects import project_manager

def _get_active_project_context() -> str:
    """Get active project path context for task descriptions."""
    project = project_manager.get_active()
    if project and project.path:
        return f"[PROJECT_PATH] {project.path}"
    return ""
```

```python
# This ensures agents know where project files should be saved/read
```

```markdown
**Note:** When a project is active, the system auto-injects `[PROJECT_PATH]` into task descriptions. Agents use this path for project files (whitepaper.md, roadmap.md, etc.).
```

### How It Works

1. When BOSS creates a task via `create_task()`, the system checks for an active project
2. If active project exists with a path (e.g., `C:\Users\lou\__MY_WORK__\STUDIO_TEST_ROOM`), it appends `[PROJECT_PATH] <path>` to the task description
3. Agents receiving the task see the actual project folder path and can save files there correctly
4. Idempotent: if `[PROJECT_PATH]` already exists in description, it won't be duplicated

### Example

Before (task description):
```
[WHAT] Write whitepaper.md [CONTEXT] New game concept
```

After (with P001 active):
```
[WHAT] Write whitepaper.md [CONTEXT] New game concept [PROJECT_PATH] C:\Users\lou\__MY_WORK__\STUDIO_TEST_ROOM
```

Agents can now save to `{PROJECT_PATH}/whitepaper.md` instead of incorrectly using `projects/P001/whitepaper.md`.
