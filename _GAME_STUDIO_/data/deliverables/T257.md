## Functions Added

### `compress_tier(tier_index: int) -> bool`
Main compression function. Handles tier N → N+1 chaining:
1. Checks if `accumulated_a` exceeds threshold
2. Logs content before compression (preserved in `data/memory/compression_logs/`)
3. Compresses via LLM callback or fallback
4. Appends summary to tier N+1's `accumulated_a`
5. Clears tier N's `accumulated_a`, keeps `summary_b` as record
6. Returns `True` if compression happened

### `check_and_compress_all() -> int`
Cascade function for T258 integration:
- Checks tiers sequentially T0→T1→T2...
- Compresses any tier that exceeds threshold
- Continues until no tier needs compression
- Returns count of compressed tiers

### `set_compress_callback(callback)`
Sets LLM compression callback: `fn(content: str, tier_index: int) -> str`

### `_log_before_compression(tier)` / `_default_compress(content, tier_index)`
Private helpers for logging and fallback compression.
