### Usage

1. Click **Projects** tab
2. Click **+ New** to add a project (enter name + external folder path)
3. Click a project to view details
4. Use **White Paper** / **Roadmap** tabs to view `{path}/white_paper.md` or `{path}/roadmap.md`
5. Double-click or use **Set Active** to mark the active project
6. **Archive** hides project, **Restore** brings it back
7. **Delete** removes reference (does NOT delete external folder)
