# Agent Fleet Coordination Patterns Research

## Summary
Three frameworks dominate multi-agent orchestration in 2026: **LangGraph** (graph-based state machines), **AutoGen** (actor-model event-driven), and **CrewAI** (role-based delegation). LangGraph offers maximum control for enterprise use; AutoGen provides distributed scalability; CrewAI enables rapid prototyping but has hierarchical delegation issues in practice.

## Key Findings

| Finding | Evidence | Implication |
|---------|----------|-------------|
| LangGraph uses directed graphs with conditional edges | Supports cyclic retry logic, human-in-loop checkpoints | Best for workflows needing precise control, branching, error recovery |
| AutoGen v0.4 adopted actor model | Event-driven async architecture, supports distributed agents | Enables hundreds of concurrent conversations, cloud deployment |
| CrewAI hierarchical mode doesn't work as documented | Tasks execute sequentially, not dynamically delegated | Use sequential process or build custom delegation logic |
| State sync remains challenging at scale | Full-state rebroadcast pattern common | Network latency disrupts timing; need message queues for large fleets |
| Three orchestration archetypes exist | Centralized, decentralized/event-driven, swarm | Match pattern to latency requirements and debugging needs |

## Analysis

### Framework Comparison

| Aspect | LangGraph | AutoGen v0.4 | CrewAI |
|--------|-----------|--------------|--------|
| **Architecture** | Directed graph with nodes/edges | Actor model, event-driven | Role-based crews |
| **State Management** | TypedDict/Pydantic, reducer logic | Message passing | Shared context |
| **Communication** | Graph edges, handoffs | Async pub/sub | Delegation flags |
| **Scalability** | Good with checkpoints | Excellent (distributed) | Limited |
| **Learning Curve** | Steep | Moderate | Gentle |
| **Production Readiness** | High | High | Medium |

### Coordination Pattern Trade-offs

**Centralized Orchestration** (Manager → Workers)
- ✅ Predictable, easy to debug, clear task ownership
- ❌ Manager bottleneck, single point of failure

**Decentralized/Event-Driven** (Pub/Sub)
- ✅ Low latency, no bottleneck, scales horizontally
- ❌ Harder to trace, eventual consistency challenges

**Subagents-as-Tools**
- ✅ Simple mental model, agents invoke other agents like functions
- ❌ Limited parallelism, deep call stacks

### Winner by Use Case

| Use Case | Recommended | Rationale |
|----------|-------------|-----------|
| Enterprise/Compliance | LangGraph | Checkpoints, audit trails, precise control |
| Distributed/Cloud-native | AutoGen | Actor model, async, language-agnostic |
| Rapid Prototyping | CrewAI | Intuitive roles, quick setup |
| Custom Control | Roll your own | Avoid framework overhead, full flexibility |

## Recommendations

| Priority | Action | Rationale |
|----------|--------|-----------|
| 1 | **Use LangGraph for production orchestration** | State persistence, checkpoints, and reducer logic provide enterprise-grade reliability |
| 2 | **Adopt event-driven pub/sub for scaling** | Centralized orchestration bottlenecks at ~10+ agents; message queues (Pulsar, Redis Streams) maintain responsiveness |
| 3 | **Avoid CrewAI hierarchical process** | Documented limitations—tasks run sequentially regardless of delegation settings |
| 4 | **Implement full-state rebroadcast cautiously** | Works for small fleets; consider delta-based updates for >5 agents |
| 5 | **Build custom for simple cases** | Subagent-as-tool pattern with ReAct loop covers 80% of use cases without framework overhead |
