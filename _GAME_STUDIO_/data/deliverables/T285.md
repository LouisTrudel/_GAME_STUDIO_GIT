  - Set cooldown timestamp before processing request

### Behavior

| Action | Result |
|--------|--------|
| Click Discuss | Opens modal, sets cooldown, starts countdown |
| Click again within 60s (frontend) | Shows "Please wait Xs" notification, blocks request |
| Direct API call within 60s | Returns 429 with Retry-After header |
| Button during cooldown | Disabled, shows "Wait Xs" countdown |
| After 60s | Button re-enables, shows "Discuss" |

### Integration
- Frontend cooldown syncs with backend - both enforce 60s
- Each suggestion ID has independent cooldown
- Countdown timer updates every second
- Works with existing debounce (500ms) which prevents rapid double-clicks
