## The Early Struggles (September 3-4, 2026)

### The QA Spam Incident
QA agent entered an infinite loop, posting "No tasks to review" every 7 seconds. The user had to alt-tab to a standard Claude CLI to manually terminate the process. Lesson: agents need guardrails against polling when idle.

## Architectural Milestones

### Taxonomy Expert (September 4)
Born from a naming consistency audit. The system was accumulating "bad names" like `get_task_status` (returned all tasks, not status). The Taxonomy agent reviews naming conventions, API contracts, and prevents technical debt.

### Context Engineer (September 4)
Created to optimize prompts for LLM consumption. Based on research into "lost in the middle" phenomenon—LLMs weight context at the start and end more heavily.

**Key findings from T015 research:**
- Tables beat prose (~60% vs ~53% accuracy)
- 2-3 examples teach better than explanations
- Critical instructions must be at START and END
- 500-1000 tokens per role file maximum

### LangChain Integration Research (September 6)
Research agent deep-dove into LangChain patterns. The synthesis (T127) produced actionable guidelines:
- `===` delimiters for reliable regex parsing
- Explicit enumeration of blocked states (+15-20% compliance)
- Position effects compliance audits

## The AB Chaining Memory System (September 6-7)

**The Problem:** Context grew unbounded. Sessions crashed on token limits.

**The Solution:** Infinite-tier AB chaining compression.

```
Pattern: [A] accumulates → exceeds threshold → compress to [B] 
       → append [B] to next tier's [A] → cascade continues
       
Tiers: T0 → T1 → T2 → T3 → ... → Tn
```

## Lessons Learned

1. **Token limits are real.** Memory compression isn't optional—it's survival.

2. **Tools must match docs.** Agents trust skill files. Ghost tools cause failures.

3. **Naming compounds.** Bad names today become tech debt tomorrow. Taxonomy matters.

4. **Position effects are measurable.** Critical rules at START and END. Reference material in middle.

5. **One agent, one task.** Parallel assignment causes invalid states.

6. **Server restarts invalidate state.** Many "bugs" were stale server state. Restart before debugging.
