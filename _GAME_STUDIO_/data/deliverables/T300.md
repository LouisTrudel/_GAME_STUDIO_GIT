### Flow

```
User clicks Discuss
        ↓
Frontend → POST /api/suggestions/{id}/discuss
        ↓
Backend creates:
  1. Research task (assigned to Research agent)
  2. Boss task (depends on Research, assigned to BOSS)
        ↓
Returns immediately: {status: "tasks_created", research_task: "T###", boss_task: "T###"}
        ↓
Frontend shows: "Discussion started: T### → T###. Check Hub & Tasks."
        ↓
Research picks up task → posts to hub while working → calls add_discussion
        ↓
Boss picks up task (after Research completes) → analyzes → calls add_discussion
        ↓
Results visible in Hub feed + stored in suggestion.discussion_history
```
