### Bugs Found



**Details:** In `studio/studio.py:260`, Raw tasks using `claude_cli` backend inject a system prompt: `"You are a helpful assistant. Consider making `claude_cli` behave the same for true parity.

**Repro:**

2. Compare behavior to backend=gemini
3. Claude gets extra system prompt that Gemini doesn't get
