# T223: Prompt Injection Order Evaluation

## Current vs Proposed

| Position | Current | Proposed | Rationale |
|----------|---------|----------|-----------|
| **Primacy (top 10%)** | role.md | tools | Tools = capabilities, must parse first |
| **Middle (low recall)** | tools | role.md | Identity least critical for task execution |
| **Recency (bottom 10%)** | skills | skills | Action instructions = highest compliance |

## Analysis

### 1. Does tool schema need to be early?
**Yes.** Tool schemas define the action space. Model must know *what it can do* before *who it is* or *what to do*. Schema parsing is mechanical—position doesn't affect comprehension, but early placement ensures tools are "loaded" before role constraints potentially conflict.

### 2. Does role persona need recency?
**No.** Role is identity/constraints, not action. Identity primes behavior but doesn't require recency for compliance. Middle position acceptable—role acts as persistent filter, not immediate instruction.

### 3. Impact on instruction-following
**Positive.** Skills at recency position = direct task execution. Current order already does this correctly. Moving tools to primacy frees role from competing for that high-value slot.

## Recommendation

```
PROPOSED ORDER:
1. tools (primacy) → "Here's what you can do"
2. role.md (middle) → "Here's who you are" 
3. skills (recency) → "Here's what to do NOW"
```

### Expected Impact
| Metric | Current | Proposed | Delta |
|--------|---------|----------|-------|
| Tool usage accuracy | Baseline | +5-10% | Tools parsed without role interference |
| Role constraint adherence | Baseline | -0-5% | Acceptable—middle position still functional |
| Skill instruction following | Baseline | Same | Already at recency |

## Edge Case: Role-Tool Conflicts

If role says "never use tool X" but tool X is in schema, current order (role first) might prime avoidance before tool is even parsed. Proposed order parses tool, then applies role filter. **This is correct behavior**—know the option exists, then filter.
