# T271 Deliverable: Deprecated Context System Audit

## Summary

The codebase has **fully migrated to AC-Memory (Accumulated Compacted Memory)** for memory/context compression. The AC-Memory system is implemented in `studio/core/memory.py` and properly integrated.

However, there are **two deprecated/parallel context systems still active** that predate or run alongside AC-Memory:

---

## Deprecated Systems Found

### 1. Hub-Level Session Summarization (Deprecated Pattern)
**Files:** `studio/core/hub.py:287-341`

| Location | Issue |
|----------|-------|
| `hub.py:55` | `self.session_summary: str = ""` - in-memory summary field |
| `hub.py:287-341` | `summarize_old_messages()` - old summarization logic |
| `hub.py:248-250` | Fallback to `self.session_summary` if file doesn't exist |

**What it does:** Extracts key decisions from old messages and stores in `self.session_summary`. Called after task completion in `studio.py:469`.

**Problem:** This is the OLD pattern. AC-Memory uses:
- Tier 0 accumulation via `_accumulate_to_tier0()` (hub.py:138-164)
- `memory_manager.check_and_compress_all()` cascade (studio.py:474-479)

**Migration needed:** Remove `summarize_old_messages()` and `self.session_summary`. AC-Memory handles this via tier compression.

---

### 2. Legacy Memory Method `add_hot()`
**File:** `studio/core/memory.py:425-440`

| Location | Issue |
|----------|-------|
| `memory.py:425-440` | `add_hot()` legacy compatibility method |
| `tasks.py:46-74` | `_log_to_memory()` still calls `memory_manager.add_hot()` |

**What it does:** Appends task completion info to Tier 0 with tags/metadata.

**Problem:** This is marked "Legacy compatibility" but is actively used. The new pattern should use `append_to_tier()` directly.

**Migration needed:** Replace `_log_to_memory()` in tasks.py to use `memory_manager.append_to_tier(0, ...)` directly.

### 3. Dual Context Injection Points

**What it does:** Two places build context prompts.

**Status:** This is INTENTIONAL (T226 optimization). `studio.py` builds optimized prompts, `agent.py` is fallback. NOT deprecated.
