## DELIVERABLE: Duplicate Server Detection

### Files Created/Modified

**NEW: `server_modules/lockfile.py`**
- `acquire_lock(port)` - Checks port binding + lock file before startup
- `release_lock()` - Cleans up lock file on shutdown
- `is_port_in_use(port)` - Socket-based port check
- `is_process_running(pid)` - Cross-platform PID check (Windows/Unix)

**MODIFIED: `server.py`**
- Import `acquire_lock`, `release_lock` from lockfile module
- Call `acquire_lock(PORT)` before uvicorn starts, exit(1) on failure
- Call `release_lock()` in lifespan cleanup

### Behavior

**On startup:**
1. Check if port 8000 is already bound → fail fast with clear message
2. Check if lock file exists with active PID → fail fast
3. Clean up stale lock files (crashed processes) automatically
4. Create new lock file with current PID

**On duplicate detected:**
```
==================================================
  ERROR: Server already running!
==================================================
Port 8000 is already in use.
Another server instance may be running.
Close the existing server or use a different port.
==================================================
```

**On shutdown:**
- Lock file removed during lifespan cleanup

### Lock File Location
`data/.server.lock` - Contains PID of running server

### Pattern Choice
Lock file + port check chosen over port-only because:
1. Port check alone fails silently if timing race
2. Lock file detects stale processes from crashes
3. Provides clear error before uvicorn even starts
