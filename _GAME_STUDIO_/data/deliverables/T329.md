### How it works
1. When user switches project via dropdown (`onProjectSwitcherChange()`):
   - `setActiveProject()` or `clearActiveProject()` is called
   - URL is updated via `updateUrlProject()`
   - `reloadHubForProject()` clears existing messages and calls `fetchHistory()`
   - `fetchHistory()` uses `apiUrl('/history')` which includes `?project=` param (from T327)
   - Backend returns messages for the new project context
