## T280 Deliverable: Backfill Memory Tiers from Historical Logs

### Summary
Created `backfill_memory_from_logs()` function in `studio/core/memory.py` that reconstructs AC-Memory tiers from historical `data/logs/*.json` files.

### Implementation

**File:** `studio/core/memory.py:423-519`

**Function:** `backfill_memory_from_logs(exclude_today=True, dry_run=False)`

| Parameter | Default | Purpose |
|-----------|---------|---------|
| `exclude_today` | True | Skip today's log (still being written) |
| `dry_run` | True | Return stats without writing files |

### Algorithm

1. **Collect logs** - Read all `data/logs/*.json` chronologically (oldest first)
2. **Format entries** - Convert `{timestamp, speaker, message}` to tier-style `[HH:MM] speaker: message...`
3. **Group by day** - Create daily summaries with key event extraction
4. **Extract key events** - Filter for: tasks, completions, approvals, errors, decisions, implementations
5. **Write tier_1.json** - Daily summaries accumulated (historical context)
6. **Cascade if needed** - If tier_1 exceeds threshold, compress to tier_2
