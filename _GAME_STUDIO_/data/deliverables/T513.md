## Fix Applied

**Added liveTokens cleanup to `studio-core.js:176-182`:**

```javascript
// Clear stale liveTokens for agents no longer in_progress
const inProgressAgents = new Set(data.data.filter(t => t.status === 'in_progress').map(t => t.assignee));
Object.keys(liveTokens).forEach(agent => {
    if (!inProgressAgents.has(agent)) {
        delete liveTokens[agent];
    }
});
```

**Behavior:**
- On every `tasks_update` WebSocket message, identifies agents with `in_progress` tasks
- Deletes `liveTokens[agent]` entries for agents no longer in progress
- Prevents stale token counts from displaying when same agent starts new task
