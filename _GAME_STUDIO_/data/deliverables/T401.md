### 2. MODERATE EFFORT: Dynamic File Tree Injection

**What**: Generate fresh file tree at agent wake-up, cache for 5 minutes.

**New file: `studio/core/file_index.py`** (~80 lines):
```python
from pathlib import Path
import time
from studio.core.paths import REPO_ROOT

_tree_cache = {"tree": "", "expires": 0}

def get_file_tree(max_depth: int = 3, max_files: int = 50) -> str:
    """Generate compressed file tree with annotations."""
    now = time.time()
    if _tree_cache["expires"] > now:
        return _tree_cache["tree"]
    
    # Walk repo, skip __pycache__, node_modules, .git
    tree_lines = []
    for p in sorted(REPO_ROOT.rglob("*")):
        if any(skip in p.parts for skip in ["__pycache__", "node_modules", ".git"]):
            continue
        rel = p.relative_to(REPO_ROOT)
        depth = len(rel.parts)
        if depth > max_depth:
            continue
        indent = "  " * (depth - 1)
        name = p.name + ("/" if p.is_dir() else "")
        tree_lines.append(f"{indent}{name}")
        if len(tree_lines) >= max_files:
            tree_lines.append("... (truncated)")
            break
    
    tree = "\n".join(tree_lines)
    _tree_cache["tree"] = tree
    _tree_cache["expires"] = now + 300  # 5 min cache
    return tree
```

**Injection**: Same as #1, use `get_file_tree()` instead of static `PROJECT_MAP`.

**Token cost**: ~150-300 tokens/request
**Token savings**: 500-3000 tokens (fresh view, no stale manifest)
