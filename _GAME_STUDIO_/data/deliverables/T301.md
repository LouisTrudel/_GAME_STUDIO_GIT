# Context Compaction Modes Research

## Summary

Threshold-based compaction is the optimal strategy for Boss context injection. Research shows ALWAYS compacting causes 60-83% information loss (especially session constraints), while NEVER wastes tokens and hits context limits. Moderate thresholds (~4096 chars for recent messages, 1024 for observations) achieve 50% cost reduction with near-zero quality degradation.

## Key Findings

| Finding | Evidence | Implication |
|---------|----------|-------------|
| ALWAYS compaction is lossy, not noisy | [arXiv: Lost in Compaction](https://arxiv.org/abs/2608.11242) — only 17% of session constraints retained | Short contexts don't benefit; compaction overhead wasted |
| Moderate thresholds yield best tradeoff | [ACON research](https://arxiv.org/pdf/2510.00615) — 4096 history/1024 observation optimal | Smaller thresholds = more LLM calls + accuracy loss; larger = higher cost |
| 50% cost reduction with <5% quality loss achievable | [NeuralTrust guide](https://neuraltrust.ai/blog/prompt-compression-guide) — compression-quality gentle curve | Threshold tuning critical; don't exceed 80% compression ratio |
| Context types need different handling | [Factory.ai](https://factory.ai/news/compressing-context) — session memory vs task history differ | Session constraints need verbatim preservation; task history compresses well |
| Current system already uses threshold (10K chars tier 0) | `memory.py:39-44` — TIER_THRESHOLDS implemented | Foundation exists; need per-block-type thresholds |

## Analysis: Three Strategies Compared

| Mode | Token Savings | Info Loss Risk | Latency | Best For |
|------|---------------|----------------|---------|----------|
| ALWAYS | High (60-80%) | HIGH (17% constraint retention) | +200-500ms per injection | Never recommended |
| THRESHOLD | Medium (40-60%) | LOW (tunable) | +latency only when triggered | Session memory, task history, message buffers |
| NEVER | None | None | Fastest | Short contexts (<1K tokens), critical constraints |

**Recommendation: Hybrid THRESHOLD with per-type configs**

The current system (`memory.py`) already implements tier-based thresholds. The gap is that Boss context injection (`hub.py:225-267`) passes raw context without per-block-type decisions.

## Recommendations

| Priority | Action | Rationale |
|----------|--------|-----------|
| 1 | Add CompactionMode enum: `ALWAYS`, `THRESHOLD(n)`, `NEVER` | Clean API for context blocks |
| 2 | Configure per-block-type: session_memory=THRESHOLD(2000), recent_messages=NEVER(last 10), task_history=THRESHOLD(1000) | Research shows different content types have different info-density |
| 3 | Preserve constraints verbatim via "constraint extraction" pass before compaction | arXiv research shows 83% constraint loss otherwise |
| 4 | Set max compression ratio 70% (never >80%) | Prevents catastrophic information loss |

```python
# In hub.py or new context_injector.py

class CompactionMode(Enum):
    ALWAYS = "always"
    THRESHOLD = "threshold"
    NEVER = "never"

BLOCK_COMPACTION_CONFIG = {
    "session_memory": {"mode": CompactionMode.THRESHOLD, "threshold": 2000},
    "recent_messages": {"mode": CompactionMode.NEVER},  # Last 15 verbatim
    "task_history": {"mode": CompactionMode.THRESHOLD, "threshold": 1000},
    "studio_purpose": {"mode": CompactionMode.NEVER},   # Always include
}

def inject_context_for_boss(blocks: dict) -> str:
    """Inject context with per-block compaction."""
    output = []
    for block_name, content in blocks.items():
        config = BLOCK_COMPACTION_CONFIG.get(block_name, {"mode": CompactionMode.NEVER})
        
        if config["mode"] == CompactionMode.NEVER:
            output.append(content)
        elif config["mode"] == CompactionMode.THRESHOLD:
            if len(content) > config["threshold"]:
                output.append(compress(content, max_ratio=0.7))
            else:
                output.append(content)
        elif config["mode"] == CompactionMode.ALWAYS:
            output.append(compress(content, max_ratio=0.7))
    
    return "\n".join(output)
```
