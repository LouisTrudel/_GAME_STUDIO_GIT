### Artist vs Image Separation

| Artist (existing) | Image (new) |
|-------------------|-------------|
| Visual specs, style guides | Actual PNG/JPG file generation |
| Color palettes (#hex) | Apply colors to generated assets |
| SVG/vector code inline | Rasterized bitmap output |
| "What it should look like" | "Here's the file" |

| Tool | Purpose |
|------|---------|

| `fetch_image` | Download from URL |
| `resize_image` | Scale to target dimensions |

### Output Convention

- All assets save to `assets/<category>/<name>.png`
- Categories: `sprites/`, `textures/`, `ui/`, `icons/`, `concept/`
- Returns file paths, not descriptions

- Compatible with existing agent loader pattern
- Color #e91e63 (pink) distinguishes from Artist #2ecc71 (green)
