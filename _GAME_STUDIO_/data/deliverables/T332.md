## T332 Deliverable: Per-Project Task Storage

### Implementation Summary

Modified `studio/core/tasks.py` and `studio/core/hub.py` to support per-project task storage following the same pattern used for memory and history.

### Changes Made

**studio/core/tasks.py:**

1. **Added import** for `get_base_path` from paths.py (line 19)

2. **Renamed constants** to `DEFAULT_*` variants with legacy aliases for backwards compatibility (lines 78-88):
   - `DEFAULT_TASKS_FILE`, `DEFAULT_ARCHIVE_FILE`, `DEFAULT_DELIVERABLES_DIR`

3. **Updated `save_deliverable()`** to accept `project_name` parameter and use `get_base_path()` (lines 91-115)

4. **Added project-aware methods to TaskManager** (lines 422-477):
   - `_get_tasks_file()` - resolves tasks.json path
   - `_get_archive_file()` - resolves tasks_archive.json path  
   - `_get_deliverables_dir()` - resolves deliverables directory
   - `set_project(project_name)` - switches to project-specific storage

5. **Updated file I/O methods** to use dynamic paths:
   - `_load_tasks()` - uses `_get_tasks_file()`
   - `_save_tasks()` - uses `_get_tasks_file()`
   - `_is_in_archive()` - uses `_get_archive_file()`
   - `archive_old_tasks()` - uses `_get_archive_file()`
   - `get_archive_stats()` - uses `_get_archive_file()`
   - `complete_task()` - passes `_project_name` to `save_deliverable()`

**studio/core/hub.py:**

1. **Added import** for `task_manager` from tasks module (line 20)

2. **Updated `set_active_project()`** to call `task_manager.set_project()` when switching projects (lines 103-151)

### Path Resolution Logic

```
get_base_path(None)      -> data/
get_base_path("default") -> data/
get_base_path("P001")    -> projects/P001/
```

When project is active (e.g., P001):
- `tasks.json` → `projects/P001/tasks.json`
- `tasks_archive.json` → `projects/P001/tasks_archive.json`
- `deliverables/` → `projects/P001/deliverables/`

### Backwards Compatibility

- Global `data/tasks.json` works when no project is active
- Legacy module-level `TASKS_FILE`, `ARCHIVE_FILE`, `DELIVERABLES_DIR` preserved
- Existing code using `task_manager` directly continues to work

### Usage

```python
# Automatic via Hub project switching
hub.set_active_project("P001")  # Tasks now use projects/P001/tasks.json

# Or direct task_manager call
from studio.core.tasks import task_manager
task_manager.set_project("P001")  # Same effect
```
