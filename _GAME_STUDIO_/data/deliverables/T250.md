## Deliverable: T250 - recall_memory Tool for Boss

### Implementation
**File:** `studio/agents/boss/tools.py:256-402`

Added `recall_memory` tool that searches memory tiers in priority order:

```
hot (current session) → warm (recent days) → cold (historical) → raw logs (fallback)
```

### Tool Schema

```python
{
    "name": "recall_memory",
    "input_schema": {
        "properties": {
            "query": "Search term (keyword match)",       # required
            "max_results": "Max results (default: 5)",     # optional
            "search_logs": "Search logs as fallback (default: true)"  # optional
        }
    }
}
```

### Usage Examples

```
recall_memory(query="economy")
# → Searches hot → warm → cold tiers for "economy"

recall_memory(query="T123", max_results=3)
# → Finds references to task T123, limited to 3 results

recall_memory(query="inventory bug", search_logs=False)
# → Only searches memory tiers, skips raw log fallback
```

### Output Format

```
=== MEMORY RECALL (HOT tier) ===
Query: 'economy' | 2 result(s)

[M00001] 2026-09-06T10:30
  Implemented shop pricing system
  tags: economy, shop, pricing

[M00002] 2026-09-06T11:15
  Currency exchange rates finalized
  tags: economy, balance
```

### Integration
- Reuses existing `memory_manager.search()` from `studio/core/memory.py`
- Falls back to `data/logs/*.json` if no tier matches
- Registered in `TOOLS` and `HANDLERS` bundles
