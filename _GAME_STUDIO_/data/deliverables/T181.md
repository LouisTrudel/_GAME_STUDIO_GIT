## Deliverable: T181 - Raw Pseudo-Agent Implementation

**Implemented 'Raw' pseudo-agent for direct LLM access.**

### Changes Made:

**1. `studio/agents/boss/tools.py`** (lines 33-35, 62-70)
- Added "Raw" to valid assignees description
- Added normalization for "raw" → "Raw" in `create_task()`

**2. `studio/studio.py`** (lines 17-20, 227-263, 459-489)
- Added `import gemini` for Raw backend
- New `_run_raw_task()` method:
  - Stateless execution (no conversation history)
  - No context injection (no role, no memory, no skills)
  - Returns plain text response
  - Default backend: gemini (free tier)
  - Graceful error handling
- Modified `_dispatch_new_tasks()`:
  - Handles "Raw" assignee before regular agent dispatch
  - Routes to `_run_raw_task()` instead of `_run_agent_task()`
  - Supports concurrent execution (counts toward MAX_CONCURRENT_AGENTS)

### How It Works:

```
BOSS creates task → assignee: "Raw" → Studio detects Raw
  → _run_raw_task() → gemini.query(description) → plain text response
  → task completed with response saved to deliverables
```

### Usage:
```python
# BOSS can now delegate quick LLM queries:
create_task(
    description="What are the top 3 game mechanics for retention?",
    assignee="Raw"
)
```

### Constraints Met:
- ✅ Raw tasks are stateless
- ✅ Always return plain text, never structured data
- ✅ Default backend: gemini (free tier)
- ✅ Fails gracefully if backend unavailable
- ✅ No agent overhead (no role/skills/context injection)
