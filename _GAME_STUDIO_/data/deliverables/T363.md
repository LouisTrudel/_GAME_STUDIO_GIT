### Race Conditions

**Global dict without locks:**
```python
# studio_metrics.py:39 - Thread A and B both read/write
_session_tokens["total_input_tokens"] += input_tokens
```

**Fix:** Add `threading.Lock()` around all access.

---

### Lock File TOCTTOU

**`lockfile.py:51-94`:** Check-then-write allows race between two processes.

**Fix:** Use atomic `open(LOCK_FILE, 'x')` which fails if file exists.
