## === Projects Tab Interface ===

### Data Structure

**File:** `data/projects.json`

```json
{
  "active_project_id": "P001",
  "projects": [
    {
      "id": "P001",
      "name": "Untitled Game",
      "path": "D:/Games/MyProject",
      "description": "First-person exploration game",
      "status": "active",
      "created_at": "2026-09-07T10:00:00Z",
      "updated_at": "2026-09-07T11:30:00Z"
    }
  ]
}
```

| Field | Type | Description |
|-------|------|-------------|
| id | string | Format: P001, P002... (auto-increment) |
| name | string | Display name (max 50 chars) |
| path | string | Absolute path to external project folder |
| description | string | Optional brief description (max 200 chars) |
| status | enum | "active" \| "archived" |
| created_at | ISO8601 | Creation timestamp |
| updated_at | ISO8601 | Last modified timestamp |

### Project Folder Structure (External)

```
{project_path}/
├── white_paper.md      # Game concept document
├── roadmap.md          # Development milestones
└── assets/             # 3D models, textures, etc.
```

**Note:** Studio reads `white_paper.md` and `roadmap.md` from the external folder. No copies stored in this repo.

### Interactions

| Action | Trigger | Result |
|--------|---------|--------|
| Select project | Click sidebar item | Load details in right panel |
| New project | Click "+ New" | Open modal: name, path (folder picker), description |
| Open folder | Click "Open Folder" | `shell.openPath(project.path)` |
| View white paper | Click "White Paper" tab | Read `{path}/white_paper.md`, display markdown |
| View roadmap | Click "Roadmap" tab | Read `{path}/roadmap.md`, display markdown |
| Archive | Click "Archive Project" | Set status="archived", remove from list |
| Show archived | Toggle button | Filter projects by status |
| Path invalid | On load | Show warning: "Project folder not found" |

### Edge Cases

| Case | Behavior |
|------|----------|
| Path doesn't exist | Red warning banner, disable document tabs |
| white_paper.md missing | Tab disabled, show "No white paper found" |
| roadmap.md missing | Tab disabled, show "No roadmap found" |
| File > 50KB | Truncate preview, show "File too large" link |
| No projects | Empty state: "No projects yet. Click + New to add one." |
| Duplicate path | Block creation: "This folder is already linked" |
