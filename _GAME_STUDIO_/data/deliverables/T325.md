### Toggle Configuration

Both fixes can be enabled/disabled via `studio/agents/boss/config.json`:

```json
{
  "name": "BOSS",
  "delegation_fixes": {
    "primacy_identity": true,   // Fix 1: Identity at start
    "recency_bookend": true     // Fix 2: Reminder at end
  }
}
```

### Loader Logic (`studio/loader.py:38-70`)

When `delegation_fixes` are enabled, `load_agent_role_md()` assembles:
1. `primacy_identity.md` (if enabled)
2. `role_base.md`
3. `recency_bookend.md` (if enabled)

When disabled, falls back to `role.md` directly.

### Integration

No changes required to `studio/agent.py`. The loader transparently returns the assembled or base role based on config. BOSS's conversational abilities preserved—only delegation enforcement added.
