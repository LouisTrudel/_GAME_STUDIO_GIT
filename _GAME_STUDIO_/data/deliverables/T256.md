## Deliverable: T256 - Refactored memory.py with AB Chaining

### Summary
Replaced the fixed 3-tier system (MemoryEntry/WarmEntry/ColdEntry) with a generic `TierData` class that enables infinite tier chaining.

### Changes Made

**Removed:**
- `MemoryEntry` class (hot tier)
- `WarmEntry` class (warm tier)  
- `ColdEntry` class (cold tier)
- `hot/`, `warm/`, `cold/` directory structure

**Added:**
- `TierData` dataclass with:
  - `tier_index` (int) - which tier (0, 1, 2, ...)
  - `accumulated_a` (str) - growing content awaiting compression
  - `summary_b` (str) - most recent compression result
  - `metadata` (dict) - tier-specific tracking
  - `compression_count` (int) - compression history

**File Structure:**
```
data/memory/
├── tier_0.json   # Session messages (threshold: 10KB)
├── tier_1.json   # Daily summaries (threshold: 50KB)
├── tier_2.json   # Archives (threshold: 200KB)
└── tier_N.json   # Infinite extension possible
```

**Size Thresholds:**
| Tier | Threshold | Purpose |
|------|-----------|---------|
| 0 | 10,000 chars | Session messages (SMALL) |
| 1 | 50,000 chars | Daily summaries (MEDIUM) |
| 2+ | 200,000 chars | Archives (LARGE) |

### Key Methods
- `get_tier(n)` - Load tier data
- `save_tier(tier)` - Persist tier
- `append_to_tier(n, content)` - Add to accumulated_a
- `search(query)` - Search across all tiers
- `get_recent(n)` - Get latest content from tier
- `get_tier_stats()` - Stats for all tiers
- `TierData.needs_compression()` - Check if over threshold

### Legacy Compatibility
- `add_hot()` method preserved, appends formatted entry to tier 0

### Ready for T257
The `TierData.needs_compression()` method and consistent structure enables T257 to implement the actual compression function for any tier N→N+1.
