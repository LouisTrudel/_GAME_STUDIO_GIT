| Section | Content | Example |
|---------|---------|---------|
| `## User Intent` | Long-term goals (abstract) | "Build pet collection game with trading economy" |

3. **+Abstraction** — "Shop system complete" > "T207, T208, T209 completed"
4. **−Parsing overhead** — Prompt-enforced markdown, no JSON schema, Boss reads directly.
5. **−Token cost** — ~1500 tokens removed (schema + function + template)
