## Implementation

### 1. Memory Tier Classes (memory.py:35-120)

| Class | Tier | Schema |
|-------|------|--------|
| `MemoryEntry` | hot | Full detail (id, timestamp, source, content, tags, task_ids, agent, outcome) |
| `WarmEntry` | warm | Daily summary (date, tasks, summary, outcomes, agents, tags, friction) |
| `ColdEntry` | cold | Semantic index (month, keywords, capabilities, lessons, task_count) |

### 2. Compression Thresholds (memory.py:28-32)

| Threshold | Value | Trigger |
|-----------|-------|---------|
| `HOT_MAX_AGE_HOURS` | 24 | Entries older than 24h → warm |
| `WARM_MAX_AGE_DAYS` | 7 | Entries older than 7d → cold |
| `WARM_MAX_SIZE_KB` | 500 | warm.json > 500KB → cold |

### 3. Background Loop (broadcast.py:287-329)

```python
async def _memory_compression_loop():
    """Runs every 5 minutes, checks triggers, compresses if needed."""
    while True:
        triggers = memory_manager.check_compression_triggers()
        if triggers:
            result = memory_manager.run_compression_cycle()
            # Broadcast stats to frontend
        await asyncio.sleep(300)
```

def _log_to_memory(task_id, task, outcome):
    """Auto-log completed/failed tasks to hot tier."""
