**Deliverable: `studio/templates/whitepaper.md`**

Created a minimal whitepaper template with 6 sections:

| Section | Purpose for BOSS |
|---------|------------------|
| **Vision** | Sets tone, informs Writer and Designer |
| **Core Loop** | Designer decomposes into mechanics, Programmer builds systems |
| **Platform** | Technical constraints for Programmer |
| **Art Direction** | Direct input for Artist |
| **Scope** | MVP vs cut-list prevents scope creep |
| **Success Criteria** | QA validation targets |

**Design decisions:**
- Tables for structured data (faster to fill, easier to parse)
- HTML comments as guidance (visible while editing, invisible when rendered)
- Every section directly maps to agent work—no decorative fields
- "Explicitly Out of Scope" prevents the common spec-creep problem
- Success Criteria are measurable, not vague ("complete one loop" not "feels good")

Template is 60 lines. Users can fill it in 10 minutes if they know their game.
