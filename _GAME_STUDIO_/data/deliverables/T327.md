### Usage

```
# Access project P001's context
studio.html?project=P001

# Access default context (no project)
studio.html

# Switch projects via dropdown (updates URL automatically)
```

### Flow

1. Frontend extracts `?project=` from URL
2. WebSocket connects with `?project=P001` if present
3. Backend calls `hub.set_active_project("P001")`
4. Memory/history managers switch to `projects/P001/memory/` and `projects/P001/history/`
5. All subsequent operations use project-specific paths
6. Switching projects via UI updates URL (no page reload required)
