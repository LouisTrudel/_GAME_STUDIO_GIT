| File | Purpose |

### Scope Definition

**Video Does:**
- Cutscene generation → `assets/video/cutscenes/`
- Trailer creation → `assets/video/trailers/`
- Animated sequences → `assets/video/sequences/`
- Tutorial clips → `assets/video/tutorials/`
- UI animations (video) → `assets/video/ui/`
- Video fetching/downloading

**Video Doesn't (clear boundaries):**
- Storyboard/shot planning (→ Designer)
- Narrative scripts (→ Writer)
- In-game animation code (→ Programmer)
- Sprite animation frames (→ Image agent)
- Background music/SFX (→ Sound agent)

### Tools Defined (10 total)

| Tool | Purpose |
|------|---------|
| `generate_cutscene` | Cinematic/narrative sequences |
| `generate_trailer` | Marketing/preview videos |
| `generate_animation` | Short animated clips |
| `generate_tutorial` | How-to/onboarding clips |
| `fetch_video` | Download from URL |
| `convert_video` | MP4/WebM/GIF conversion |
| `trim_video` | Cut to duration |
| `concat_video` | Join multiple clips |
| `add_audio_track` | Overlay audio onto video |
| `extract_frames` | Export frames as images |

### Key Design Decisions

1. **Format strategy**: MP4 (H.264) for standard video, WebM (VP9) for alpha channel support, GIF for social/previews
2. **Resolution defaults**: 1080p for cinematics/trailers, 720p for tutorials/web
3. **Integration notes**: Documented collaboration with Sound agent for audio, Writer for text overlays
4. **Consistent structure**: Matches IMAGE and SOUND patterns exactly (TOOLS list, HANDLERS dict, stub returns)
