## Recommended Minimal Archive Schema

```json
{
  "id": "T###",
  "desc": "[100 char truncated description]",
  "agent": "Programmer",
  "outcome": "ok|fail|error",
  "at": "2026-09-06T20:33:40",
  "tokens": { "in": 17940, "out": 599, "usd": 0.045 },
  "friction": "retry|error|tool_error|high_cost|null"
}
```

| Field | Rationale |
|-------|-----------|
| `id` | Required for audit trail, deliverable reference |
| `desc` | Truncated to 100 chars - full context in deliverables |
| `agent` | Required for per-agent metrics |
| `outcome` | Collapsed from status - only 3 terminal states |
| `at` | `completed_at` only - `created_at` adds no value |
| `tokens` | Collapsed cost object - only fields ever queried |
| `friction` | Preserved for taxonomy/improvement analysis |

## Fields to Strip

```python
def to_archive_dict(self) -> dict:
    """Minimal schema for archive storage."""
    outcome = "ok"
    if self.status == TaskStatus.FAILED:
        outcome = "fail"
    elif self.status == TaskStatus.ERROR:
        outcome = "error"
    
    return {
        "id": self.id,
        "desc": self.description[:100],
        "agent": self.assignee,
        "outcome": outcome,
        "at": self.completed_at.isoformat() if self.completed_at else None,
        "tokens": {
            "in": self.cost_input_tokens or self.total_input_tokens,
            "out": self.cost_output_tokens or self.total_output_tokens,
            "usd": round(self.cost_usd, 4),
        },
        "friction": self._compute_friction_category(),
    }
```
