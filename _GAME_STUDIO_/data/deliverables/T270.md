## What's Broken

### 1. **Tool Schema Mismatch** (CRITICAL)

**File:** `data/session_memory.md:21`

```
Error - update_session_memory() got an unexpected keyword argument 'summary'
```

**Root Cause:** Agent tried calling with `{"summary": "..."}` but schema expects:
- `session_overview` (required)
- `active_context` (required)
- `key_decisions` (optional array)
- `completed_milestones` (optional array)

**Impact:** Session memory update silently fails.

### 2. **No Compression Callback Set** (CRITICAL)

**File:** `studio/core/memory.py:97-105`

```python
self._compress_callback: Optional[CompressionCallback] = None
```

The `MemoryManager.set_compress_callback()` is **never called** anywhere in the codebase. When Tier 0 exceeds 10KB threshold:
- Falls back to `_default_compress()` (line 192) - simple keyword extraction
- Works but loses semantic content

**Impact:** No LLM-powered compression. Fallback is low-quality.

### 3. **Summarize Callback Not Wired**

**File:** `studio/core/hub.py:61`

```python
self._summarize_callback = None
```

`Hub.set_summarize_callback()` exists but no code calls it. The 50-message trigger at `hub.py:117` **never fires**.

**Impact:** Session memory never auto-updates.

### 4. **Ghost Tool in Documentation**

The Context agent's role mentions `update_session_memory` tool, but when invoked:
- Agent uses wrong parameter names (schema drift)
- Documentation says "summary" parameter exists - it doesn't
