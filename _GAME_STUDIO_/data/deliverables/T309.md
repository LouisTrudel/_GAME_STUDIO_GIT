## Deliverable

=== HISTORY COMPRESSION TIERS ===
Depends: studio/core/memory.py (existing), studio/studio.py (existing)
Pattern: Hierarchical Compression - chosen over flat tiers (semantic meaning at each level)

### New File: `studio/core/history.py`

Implements the tiered history compression system:

| Tier | Triggers | Promotes To | Output |
|------|----------|-------------|--------|
| Draft | Memory T0 compression, session end | Chapter | Session narrative |
| Chapter | 5 drafts OR epoch end | Book | Epoch narrative |
| Book | 3 chapters OR phase complete | Collection | Phase narrative |
| Collection | 5 books OR portfolio review | None (top) | Archive narrative |

### Integration Points

1. **memory.py** - Added `set_history_tier_callback()` to trigger history tiers on compression
2. **studio.py** - Wired callbacks:
   - `_trigger_history_tier()`: Maps memory tiers → history tiers
   - `_generate_tier_narrative()`: Writer produces tier-specific narratives

### Storage

```
data/history/
├── tier_state.json          # Tier accumulation state
├── draft_2026-09-07_1.md    # Draft narratives
├── chapter_2026-09-07_1.md  # Chapter narratives
├── book_2026-09-07_1.md     # Book narratives
└── collection_2026-09-07_1.md # Collection narratives
```

### Trigger Flow

```
Memory T0 compresses → trigger_draft() → Writer narrative → save draft_*.md
                                      → append to Chapter tier
                                      
Chapter.item_count >= 5 → compress → Writer narrative → save chapter_*.md
                                   → append to Book tier
                                   
(cascade continues to Collection)
```

### Usage

```python
from studio.core.history import history_manager

# Manual triggers (automatic triggers are wired via memory compression)
history_manager.trigger_session_end(session_summary)  # End of session
history_manager.trigger_phase_complete("MVP", phase_summary)  # Milestone
history_manager.trigger_portfolio_review(["project1", "project2"])  # Archive

# Query
stats = history_manager.get_stats()  # Tier utilization
narratives = history_manager.list_narratives("chapter")  # Saved files
```
