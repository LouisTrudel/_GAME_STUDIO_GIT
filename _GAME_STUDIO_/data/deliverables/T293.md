### Usage Flow
1. User clicks **Approve** on a suggestion card
2. Modal appears with 5 stars and "Click a star to rate" label
3. Hovering stars shows preview highlight + label ("Poor", "Fair", "Good", etc.)
4. Clicking a star selects it, enables **Accept** button
5. Clicking **Accept** sends `{ decision: 'approved', rating: N }` to backend
6. Clicking **Cancel** closes modal without approving

### API Contract
The PATCH `/suggestions/{id}` endpoint now receives an optional `rating` field (1-5 integer) when approving. Backend should persist this in `data/suggestions.json`.
