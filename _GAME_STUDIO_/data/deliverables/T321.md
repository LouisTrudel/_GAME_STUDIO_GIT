## === T321 DELIVERABLE: Project-Aware Path Switching ===

**Depends:** projects.py (existing)
**Pattern:** Path delegation with fallback to default

### Implementation Summary

Created a utility module and updated memory/history managers to support project-specific data storage paths.

### Files Created

**`studio/core/paths.py`** - Path resolution utility
```python
def get_base_path(project_name: Optional[str] = None) -> Path:
    """Returns data/ for None/default, projects/<name>/ otherwise"""

def get_memory_dir(project_name: Optional[str] = None) -> Path:
    """Returns memory directory for project"""

def get_history_dir(project_name: Optional[str] = None) -> Path:
    """Returns history directory for project"""
```

### Files Modified

**`studio/core/memory.py`**
- Added `project_name` param to `MemoryManager.__init__`
- Added `set_project(project_name)` method to switch paths
- Changed `_tier_path()`, `_ensure_dirs()`, `_log_before_compression()` to use instance `_memory_dir`

**`studio/core/history.py`**
- Added `project_name` param to `HistoryManager.__init__`
- Added `set_project(project_name)` method to switch paths
- Changed `_save_state()`, `_load_state()`, `_save_narrative()`, `list_narratives()` to use instance `_history_dir`

**`studio/core/hub.py`**
- Added `set_active_project(project_id)` method that:
  1. Updates `project_manager.active_project_id`
  2. Calls `memory_manager.set_project(folder)`
  3. Calls `history_manager.set_project(folder)`
- Added `get_active_project()` for convenience

**`server_modules/routes.py`**
- Updated `/api/projects/{project_id}/set-active` to use `hub.set_active_project()`
- Added `/api/projects/clear-active` endpoint to reset to default

### Usage

```python
# From API (UI dropdown)
POST /api/projects/P001/set-active  # Switch to project P001
POST /api/projects/clear-active     # Switch to default (no project)

# From code
from studio.core.hub import hub
hub.set_active_project("P001")      # Memory/history now use projects/P001/memory/, projects/P001/history/
hub.set_active_project(None)        # Memory/history now use data/memory/, data/history/
```

### Path Resolution

| project_name | memory path | history path |
|-------------|-------------|--------------|
| `None` | `data/memory/` | `data/history/` |
| `"default"` | `data/memory/` | `data/history/` |
| `"P001"` | `projects/P001/memory/` | `projects/P001/history/` |

### Integration

When user selects project in Hub dropdown → API calls `/api/projects/{id}/set-active` → Hub switches memory/history managers → All subsequent reads/writes use project-specific paths.
