### Usage

BOSS can now specify backend when creating Raw tasks:
```
<tool>create_task
description: What are the best game mechanics?
assignee: Raw
backend: gemini
</tool>
```

- Default backend is `gemini` if not specified
- Existing tasks without backend field will continue to work
- Future backends (ollama, openai) return clear "not yet implemented" errors
