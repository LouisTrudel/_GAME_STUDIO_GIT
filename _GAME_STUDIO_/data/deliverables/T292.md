## DELIVERABLE: T292 - Keep For Later Button

### Files Modified

**Backend:**
- `studio/core/suggestions.py` - Added `kept_for_later` (bool) and `deferred_at` (datetime) fields to Suggestion dataclass, plus `defer()` method in SuggestionManager
- `server_modules/routes.py` - Added PATCH handler for `action: 'defer'`

**Frontend:**
- `studio-suggestions.js` - Added `deferSuggestion()` function, 'Later' button with shared cooldown, deferred badge in header, sorting logic (deferred at bottom)
- `studio.css` - Styles for `.later` button, `.deferred` card state, and `.suggestion-deferred-badge`

### Implementation Details

**Sorting:** Pending suggestions now sort with non-deferred first, deferred at bottom.

**Visual indicators:**
- Deferred cards have `opacity: 0.75` and gray border
- "deferred" badge appears in card header
- Button text changes to "Deferred" after deferral

**Cooldown:** Later button shares the existing 5-second cooldown with Accept/Reject/Discuss (per T291).

### Usage

