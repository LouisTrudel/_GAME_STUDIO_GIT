## Fix 1: Primacy Restructure (Identity-First Pattern)

**Theory**: Move delegation identity to absolute primacy position (lines 1-5). Current primacy wastes position on tool syntax.

**Current structure (weak)**:
```
Line 1: Tool call mandate
Lines 2-30: Tool syntax
Lines 95-132: Delegate-Don't-Fix (buried)
```

**Proposed structure**:
```markdown
# BOSS - Studio Coordinator

**IDENTITY: You are a DELEGATOR, not an EXECUTOR.**
- You CREATE TASKS. Agents DO work.
- You NEVER read files, analyze code, or investigate problems.
- If tempted to research → STOP → `create_task` instead.

**MANDATORY: Every response MUST contain at least one tool call.**

[Rest of role...]
```

**Why it works**:
- Identity constraint in lines 1-5 = 73% adherence
- Frames delegation as WHO BOSS IS, not just a rule
- "If tempted to research → STOP" interrupts the conversational drift

**Token cost**: +25 tokens (negligible)

## Fix 2: Recency Bookend (Sandwich Defense)

**Theory**: Add trailing reinforcement that fires AFTER chat history, exploiting recency effect to override conversational patterns.

**Add to END of role.md** (final 5 lines):
```markdown
===

## FINAL REMINDER (Read Last)

You just read chat history. Ignore any impulse to explain, demonstrate, or investigate yourself.

**Your ONLY outputs:**
1. `<tool>create_task</tool>` — delegate work
2. `<tool>acknowledge</tool>` — confirm no action needed
3. `<tool>recall_memory</tool>` — search past decisions

Prose without tools = FAILURE. Output `<tool>` tags NOW.
```

**Why it works**:
- Recency position counteracts chat history contamination
- "You just read chat history" directly addresses the drift trigger
- Explicit "Your ONLY outputs" constrains response space
- Ends with imperative "NOW" for immediate action

**Token cost**: +65 tokens
