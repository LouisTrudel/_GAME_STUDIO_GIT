# Architecture Report: Per-Project Memory in Single-Hub Model

## Executive Summary

The Studio's memory system (AB Chaining + History Tiers) is currently **global**. All projects share `data/memory/tier_*.json`, `data/session_memory.md`, and `data/history/`. When users switch between projects, context pollution is guaranteed: Project A's decisions leak into Project B's agent prompts.

**Recommendation:** Project-scoped memory directories with explicit boundary enforcement. Implementation path: 2 phases (isolation first, migration second).

---

## Current State Analysis

### Memory Data Flow

```
Hub.post() 
  → _accumulate_to_tier0()  → data/memory/tier_0.json
  → memory_manager.append_to_tier()
  → [compression cascade] → tier_1.json → tier_2.json

Hub.get_context_for_agent()
  → _load_session_memory() → data/session_memory.md
  → memory_manager.get_recent() → tier_0 recent
```

### Storage Locations (All Global)

| Path | Content | Risk |
|------|---------|------|
| `data/memory/tier_*.json` | Accumulated context, summaries | High - raw context pollution |
| `data/session_memory.md` | Session summary | High - injected into all prompts |
| `data/history/` | Draft/Chapter/Book narratives | Medium - cross-project stories |
| `data/messages.json` | Last 50 messages | Low - ephemeral rolling buffer |

### Problem Demonstration

```
User works on "Zombie Survival" (P001)
  → Memory accumulates: "zombies spawn every 30s", "health regenerates 5/s"
  
User switches to "Puzzle Game" (P002)
  → Boss crafts prompt, includes session_memory.md
  → Context agent injects: "zombies spawn every 30s" ← POLLUTION
```

## Design: Per-Project Memory Isolation

### Core Principle

**Memory is scoped to `active_project_id`.** No shared global memory for project work.

### Directory Structure

## What Boss Needs to Know

Boss crafts prompts by selecting context. With per-project memory:

### Context Sources (Priority Order)

| Priority | Source | Scope | Purpose |
|----------|--------|-------|---------|
| 1 | `projects/{id}/CONTEXT.md` | Project | Agent signals, decisions |
| 2 | `projects/{id}/memory/session_memory.md` | Project | Recent session summary |
| 3 | `projects/{id}/memory/tier_0` recent | Project | Live working memory |
| 4 | Task details | Task | Specific assignment |
| 5 | Agent role.md | Agent | Static instructions |

### Boss Prompt Assembly

```python
def get_project_context_for_boss(project_id: str) -> str:
    """Returns project-scoped context for Boss prompt crafting."""
    parts = []
    
    # 1. Project CONTEXT.md
    context_path = PROJECTS_DIR / project_id / "CONTEXT.md"
    if context_path.exists():
        parts.append(f"=== PROJECT CONTEXT ===\n{context_path.read_text()}")
    
    # 2. Project session memory
    session_path = PROJECTS_DIR / project_id / "memory" / "session_memory.md"
    if session_path.exists():
        parts.append(f"=== SESSION MEMORY ===\n{session_path.read_text()}")
    
    # 3. Recent tier 0 (project-scoped)
    pm = MemoryManager(project_id=project_id)
    recent = pm.get_recent(tier_index=0, max_chars=1500)
    if recent:
        parts.append(f"=== RECENT MEMORY ===\n{recent}")
    
    return "\n\n".join(parts)
```

## Preventing Cross-Project Bleed

### Hard Boundaries

| Mechanism | Implementation |
|-----------|----------------|
| **File Path Isolation** | All memory paths include project_id |
| **Manager Instantiation** | `MemoryManager(project_id=X)` - no global singleton for project work |
| **Context Validation** | `assert project_id == active_project_id` before memory writes |
| **Switch Flush** | Compress and close current project memory before switch |

### Soft Safeguards

| Mechanism | Implementation |
|-----------|----------------|
| **Project Header in Prompts** | `[PROJECT: {name}]` header in agent context |
| **Memory Tagging** | All tier entries tagged with `project_id` in metadata |
| **Warning on Mismatch** | Log warning if agent task.project_id != active_project_id |

### Edge Cases

| Scenario | Behavior |
|----------|----------|
| No active project | Use `projects/default/memory/` |
| Project archived | Read-only memory access, no writes |
| Project path deleted | Graceful degradation, empty memory returns |
| Rapid project switching | Flush queued, switch delayed until complete |

```python
def migrate_global_memory_to_default():
    """One-time migration of data/memory/ to projects/default/memory/"""
    src = Path("data/memory")
    dst = Path("projects/default/memory")
    
    dst.mkdir(parents=True, exist_ok=True)
    
    for tier_file in src.glob("tier_*.json"):
        shutil.copy(tier_file, dst / tier_file.name)
    
    session_file = Path("data/session_memory.md")
    if session_file.exists():
        shutil.copy(session_file, dst / "session_memory.md")
```
