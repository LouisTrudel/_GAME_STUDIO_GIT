### Flow

```
Tier N exceeds threshold
    ↓
compress_tier() runs
    ↓
Content compressed to summary_b
    ↓
Summary appended to Tier N+1
    ↓
_generate_history_narrative() called with old content
    ↓
Writer agent invoked with narrative prompt
    ↓
Narrative saved to data/history/{date}_epoch{tier}_{count}.md
```

### Output Format

Files saved as: `data/history/2026-09-07_epoch0_3.md` (date, tier index, compression count)

Writer produces markdown with format:
```
# History: Epoch {N} (Tier {X})

[Narrative prose about what happened during this epoch]

---
*Recorded: [date]*
```

### Error Handling

- Non-fatal: failures logged but don't break compression flow
- Missing Writer agent: logged and skipped
- Empty narrative: logged and skipped
- Directory created automatically if missing
